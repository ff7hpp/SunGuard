# Heliofield

واجهة عرض محلية لمشروع عبير. تعرض 500 لوح افتراضي ومؤشرات وقراءات تجريبية.

## النسخة الحالية

- أوضاع ألوان Dark وCalm وLight مع حفظ الاختيار داخل المتصفح.
- مشهد 3D قابل للدوران بالسحب، والتحريك بالسحب بزر الفأرة الأيمن، والتقريب بعجلة الماوس.
- خريطة 2D بديلة تعمل بالماوس ولوحة المفاتيح.

1. افتح `index.html` في متصفح حديث. يستخدم المشهد WebGL 2، وتتوفر خريطة 2D بديلة.
2. مرّر عجلة الماوس فوق المشهد أو اضغط **Top view**. افتح **R05-C03** لتجربة قراءات اللوح والتنبيه.
3. جرّب ملاحظة صيانة أو أمر عزل افتراضي. تظهر الأحداث في **Activity log** خلال الجلسة الحالية، وإعادة تحميل الصفحة تعيد حالة العرض الأصلية.

## البناء والفحص

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
```

مصدر المشهد في `scene.js` والبيانات التجريبية في `farm.js`. ملف التشغيل المجمّع في `build/app.js`. يكفي إغلاق صفحة المتصفح لإيقاف النموذج.
