# Heliofield

واجهة عرض محلية لمشروع عبير. تعرض 500 لوح افتراضي ومؤشرات وقراءات تجريبية.

## النسخة الحالية

- أوضاع ألوان Dark وCalm وLight مع حفظ الاختيار داخل المتصفح.
- مشهد 3D قابل للدوران بالسحب، والتحريك بالسحب بزر الفأرة الأيمن، والتقريب بعجلة الماوس.
- خريطة 2D بديلة تعمل بالماوس ولوحة المفاتيح.

1. افتح `index.html` في متصفح حديث. يستخدم المشهد WebGL 2، وتتوفر خريطة 2D بديلة.
2. مرّر عجلة الماوس فوق المشهد أو اضغط **Top view**. افتح **R05-C03** لتجربة قراءات اللوح والتنبيه.
3. جرّب ملاحظة صيانة أو أمر عزل افتراضي. تظهر الأحداث في **Activity log** خلال الجلسة الحالية، وإعادة تحميل الصفحة تعيد حالة العرض الأصلية.

## البناء والفحص

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
```

مصدر المشهد في `scene.js` والبيانات التجريبية في `farm.js`. البناء ينشئ مجلد `dist/` الجاهز للنشر، ويكفي إغلاق صفحة المتصفح لإيقاف النموذج.

## المحاكي الحي المحلي

```powershell
npm.cmd run simulate
```

ثم افتح `http://127.0.0.1:4173/`. ينشئ المحاكي قاعدة SQLite محلية في `data/heliopulse.db` (لا تُرفع إلى Git)، ويحتوي 500 لوحاً وقراءة جديدة كل دقيقة. من صفحة **Analytics** يمكن اختيار Widgets وتشغيل سيناريوهات: `normal` و`dust` و`overheat` و`shading` و`inverter` و`missing`.

زر **Start 15-minute simulation** يشغل دورة حياة افتراضية من 15 فترة: مراقبة مستقرة، أعطال (غبار/تظليل/عاكس/حرارة/فقد بيانات)، ثم صيانة وتعافٍ. كل دقيقة حقيقية تضيف قراءة جديدة في SQLite وتمثل فترة من السنة الافتراضية. زر **Advance one minute** يسرّع العرض مع المحافظة على نفس التسلسل.

> نسخة Vercel هي واجهة Static فقط؛ ستعرض **Demo fallback** لأن SQLite والمحاكي يحتاجان runtime محلياً أو backend مستضافاً منفصلاً. لا تدّعي النسخة المنشورة وجود قاعدة بيانات حية.

## Neon والبيانات التاريخية

تستخدم واجهات `/api/snapshot` و`/api/history` بيانات PostgreSQL المستوردة عند إعداد `DATABASE_URL`. تحفظ الجداول القيم العشرية الأصلية ووقت CSV المحلي ووقته المقابل في UTC، بافتراض أن وقت الملف هو Europe/Istanbul. لا يحتوي الملف على قياسات الكفاءة أو التردد؛ تظهر هذه القيم على أنها غير متاحة. لوحة البيانات تعتمد على آخر عينة مستوردة، وليس على قراءات مباشرة جديدة.

```powershell
npm.cmd run neon:migrate
npm.cmd run neon:import -- SunGuard7days.csv
npm.cmd run simulate
```

يعيد الاستيراد الآمن استخدام مفتاح اللوح والوقت: البيانات المطابقة لا تتكرر، والتعارض يوقف العملية ويتراجع عنها. تتطلب الهجرة والاستيراد `DATABASE_URL_UNPOOLED`، وتستخدم الواجهة الخادمية `DATABASE_URL` المجمع. احفظهما في `.env.local` محلياً وفي متغيرات البيئة على Vercel؛ لا تضفهما إلى Git. يتطلب نشر واجهات Vercel إعداد `DATABASE_URL` في إعدادات المشروع وإعادة النشر. المحاكاة التفاعلية متاحة من الخادم المحلي؛ واجهات Vercel الحالية للقراءة فقط.
