# SunGuard

لوحة مراقبة طاقة شمسية مبنية على **بيانات مسجّلة** لمدة سبعة أيام. لا توجد مستشعرات حية في هذا المشروع: يعمل الموقع كمحاكاة إعادة تشغيل، فتتغير الخريطة والتحليلات والتنبيهات والمخططات وفق الدقيقة المسجّلة المختارة.

## ما الذي يتضمنه المشروع؟

- 300 لوحاً و1,070,811 قراءة مستوردة.
- سبعة أيام: 1–7 أكتوبر 2026، من 09:00 إلى 17:29 بتوقيت Istanbul.
- تشغيل/إيقاف وإعادة تشغيل للقراءات المسجلة بسرعات مختلفة.
- تحليلات ومخططات وتنبيهات متزامنة مع نفس لحظة إعادة التشغيل.
- SQLite محلية تُبنى من بيانات مضغوطة موجودة في المستودع.

## التشغيل المحلي

راجع [SETUP.md](SETUP.md). الملخص:

```bash
npm ci
npm run setup
npm run simulate
```

ثم افتح `http://127.0.0.1:4173/`.

لا يلزم Neon ولا أي متغيرات بيئة أو مفاتيح عند التشغيل المحلي.

## التطوير والفحص

```bash
npm test
npm run build
```

ملف قاعدة البيانات `data/sunguard.db` محلي ومُستثنى من Git. مصدر البيانات القابل للمشاركة هو `dataset/SunGuard7days.csv.gz`.
